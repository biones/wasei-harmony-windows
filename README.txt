Wasei Harmony Prototype v1.0.0
================================

Windows 10/11 (64-bit) 用の和声配置候補生成プロトタイプです。
Python のインストールは不要です。

GitHub の「Code」から「Download ZIP」を選び、ダウンロードしたZIPを展開してください。
ZIP内のファイルを直接実行したり、起動用ファイルだけを個別に保存したりしないでください。

最初に「かんたん起動.bat」をダブルクリックしてください。
文字化けなどで起動できない場合は、同じ内容の「start.bat」を実行してください。
画面の案内に従って、和音進行、開始配置、表示候補数を入力します。
結果は outputs フォルダ内の result.html と result.csv に保存されます。

起動できない場合は「diagnose.bat」を実行し、作成された
startup-diagnostic.txt をサポート窓口へお送りください。

対象範囲
--------

対象調:
  C major（ハ長調）のみ

対象和音:
  I, IV, V（いずれも基本形）

開始配置:
  S,A,T,B の順に、C5,G4,E4,C3 のように入力します。

入力例:
  進行: I IV V I
  開始配置: C5,G4,E4,C3

和音記号は半角の I, IV, V のほか、IME 変換による Ⅰ, Ⅳ, Ⅴ や
全角英字で入力した場合も自動的に変換されます。

判定対象:
  声部交差
  配置限界
  導音重複
  連続完全5度・8度
  減5度から完全5度
  外声の並達5度・8度
  並達1度
  V から I への導音解決
  極端な跳躍

制限事項
--------

本成果物は限定範囲のプロトタイプです。
属7、属9、準固有和音、転調、芸大和声全体の例外処理には対応していません。
長い進行では候補探索に時間がかかる場合があります。
HTML の楽譜表示にはインターネット接続が必要です。

Windows の警告が表示される場合
------------------------------

本実行ファイルには商用のコード署名証明書を付与していないため、Windows SmartScreen
の確認画面が表示される場合があります。配布されたZIPから展開したファイルであることを
確認したうえで実行してください。

ファイル確認
------------

SHA256.txt には WaseiHarmony.exe の SHA-256 ハッシュ値を記載しています。
確認する場合は、同じフォルダで次のコマンドを実行してください。

  certutil -hashfile WaseiHarmony.exe SHA256
