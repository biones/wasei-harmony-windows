Wasei Harmony Prototype v1.1.0
================================

Windows 10/11 (64-bit) 用の和声配置候補生成プロトタイプです。
芸大和声 第1巻の全範囲（基本三和音、転回形、四六、属七、属九、根音省略、偽終止、短調）に対応しています。
Python のインストールは不要です。

配布されたZIPを右クリックして「すべて展開」してください。
ZIP内のファイルを直接実行したり、ファイルを個別に取り出したりしないでください。

最初に「WaseiHarmony.exe」を直接ダブルクリックしてください。
画面の案内に従って、調（Key）、和音進行、開始配置、表示候補数を入力します。
結果は outputs フォルダ内に自動保存されます：
  - result.html : ブラウザで閲覧できる五線譜（大譜表）楽譜
  - result.pdf  : 印刷・保存用の五線譜PDF楽譜
  - result.mid  : DAW（Studio One, Cubase等）や楽譜ソフトで再生できる標準MIDIファイル
  - result.csv  : Excelで開ける配置構成音データ

起動できない場合は「diagnose.bat」を実行し、作成された
startup-diagnostic.txt をサポート窓口へお送りください。

対象範囲（芸大和声 第1巻 完全対応）
----------------------------------

対象調:
  C major（ハ長調）, a minor（イ短調）, c minor（ハ短調）

対象和音:
  ・基本三和音:
      I, II, IV, V, VI
  ・第1転回形:
      I6, II6, IV6, V6, VI6
  ・第2転回形（四六の和音）:
      I64, IV64, V64 （終止的四六、経過的四六、刺繍的・保続的四六）
  ・属七およびその転回形:
      V7, V56, V34, V2
  ・属九:
      V9
  ・根音省略形:
      -V7（VII）, -V9（VII7）, VII6, VII56, VII34, VII2
  ・終止形:
      正格終止、偽終止（V -> VI）

※ 芸大和声の表記（I1, I2, V71, V72, V73, -V7など）もそのまま入力できます。
※ 和音記号は半角のほか、IME 変換（Ⅰ, Ⅳ, Ⅴ, Ⅵ）や全角英数字でも自動変換されます。

開始配置の入力例:
  C長調: C5,G4,E4,C3
  イ短調: A4,E4,C4,A2
  ハ短調: C5,G4,Eb4,C3
  区切りには半角カンマ、全角カンマ、読点、空白が使用できます。

判定対象ルール:
  声部交差の禁止
  配置限界（上3声はオクターブ以内、T-B間は12度以内）
  導音重複の禁止
  連続完全5度・8度の禁止
  減5度から完全5度の禁止
  外声の並達5度・8度の禁止
  並達1度の禁止
  V から I への導音解決
  属七・属九の限定進行（第7音・第9音の下行解決、芸大和声例外規則対応）
  四六の和音の適法用法判定（K2終止、経過、保続）
  偽終止における第3音重複判定
  極端な跳躍の抑制

制限事項
--------

本成果物は芸大和声第1巻の範囲に対応したプロトタイプです。
第2巻以降の和音（副七、ドッペルドミナント、ナポリ、増6度、転調など）には対応していません。
長い進行では候補探索に数十秒かかる場合があります。

Windows の警告が表示される場合
------------------------------

本実行ファイルには商用のコード署名証明書を付与していないため、Windows SmartScreen
の確認画面が表示される場合があります。配布されたZIPから展開したファイルであることを
確認したうえで実行してください。

ファイル確認
------------

SHA256.txt には WaseiHarmony.exe の SHA-256 ハッシュ値を記載しています。
確認する場合は、同じフォルダで次のコマンドを実行してください。

  certutil -hashfile WaseiHarmony.exe SHA256
